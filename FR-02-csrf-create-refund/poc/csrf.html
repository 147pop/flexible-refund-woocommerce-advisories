CSRF PoC — wp_ajax_fr_refund_request (creation path, no nonce)

Finding B2 (CWE-352). The creation path of Ajax::create_refund() (request_id == 0) checks capabilities but not a nonce (only the update path, request_id > 0, calls check_ajax_referer). A logged-in shop_manager/admin who loads this page triggers a real, approved refund on the chosen order — no token, cross-site.

Configure below: TARGET = store origin, ORDER_ID = order to refund, ITEM_ID = a line-item id of that order (from wp_woocommerce_order_items.order_item_id; small, enumerable integer).
